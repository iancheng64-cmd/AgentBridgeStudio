# 0.4.2 設備選擇修正

日期：2026-10-03。

問題：已儲存設備清單及新增入口只存在於 Codex 設定分支，Claude Code 模式只有現有設備的表單，無法直覺切換／新增另一台設備。

修正：將「連接設備」選單移到兩個模式共用的位置；新增設備建立新的 profile ID，清空主機、使用者及密碼，保留現有設備。選擇不同設備時中斷目前模式的旧連線，再載入選取設定。自動連線僅適用於與已儲存目標一致的設定；填寫新設備或修改既有目標時，等待明確儲存／連線。

驗證：renderer/main 完整 build 通過；連線選擇與憑證隔離 4 項測試通過。正式 /Applications 的原生 UI 已讀回 Claude 模式中的設備選單與新增按鈕；新增後主機／使用者為空，原設備仍列於選單，切回原設備後原主機、使用者及已儲存密碼狀態恢復。真實 SSH 仍因遠端主機未連通而逾時，不代表新設備已配對成功。

正式版：0.4.2。app.asar SHA-256：`d0162da4fb293b74184030d637632f96b8b4cc20f00d0a3ff290023fa994dd30`。

依使用者先前的 SSD 清理要求，完成安裝驗收後刪除本次開發依賴、生成的 dist、Swift helper staging 與替換的舊 App。保留原始碼、正式 App 與使用者資料；後續重建需重新安裝開發依賴。

追加實機驗證：Codex 模式亦讀回共用設備選單／新增按鈕；切回 Claude 後新設備表單仍保留，沒有觸發空白目標連線。臨時建置檔與舊版已清除。
