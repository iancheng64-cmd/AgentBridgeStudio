# AgentBridge Studio 0.5.7 能力與驗收界線

直接描述任務，Agent 依實際可用工具選擇操作。Mac 安裝包包含核心工具、Node、原生電腦工具及瀏覽器；不需要為這些能力另外下載套件。模型與帳戶由所選 Runtime 提供，原生登入、版本相容性及網路仍需就緒。

| 能力 | 實作與界線 |
| --- | --- |
| 檔案讀写／列出／資訊／複製／移動 | 既有 Mac 工具；最高權限解除 App 路徑限制，OS 權限仍適用。管理員唯讀透過系統密碼視窗。文字單檔 1 MiB。 |
| 檔名搜尋 | 略過 symlink；最多 10,000 項／500 筆；無權子目錄會略過並回報，不讓全部結果失敗。根目錄無權則失敗。 |
| 文字內容搜尋 | literal、區分大小寫、含行號；最多 500 行，每行 2,000 字元、總讀取 32 MiB；跳過不可讀／二進位／過大檔案。 |
| 精準編輯 | 唯一原文匹配與選用 SHA-256，衝突不覆蓋；原子保存並保留 Unix mode。不是完整 Git patch 引擎。 |
| 命令執行 | Shell 或包內 Node JavaScript；4 個並行程序、30 分鐘上限，輸出保留最近 128 Ki 字元與游標；非零 exit 標為失敗。 |
| 命令生命週期 | 可輸入 stdin、查詢輸出、停止；停止任務、回合結束或關閉通道清理程序群組。不是離線排程器。 |
| 任務進度 | 以 taskId 保存目標、步驟、證據及下一動作；版本檢查避免遺失更新；跨連線保存於 App 私有資料夾，不放進來源發行包。模型需實際呼叫保存工具。 |
| 內建工作指南 | 開發、研究、電腦操作、失敗恢復；無需下載 Skills。仍須遵守使用者要求及專案 AGENTS.md。 |
| 研究／網頁 | 包內瀏覽器可搜尋、導航、讀取網頁；文字網頁讀取不帶登入 Cookie，20 秒／1 MiB／5 次轉址上限。登入、動態頁使用瀏覽器。 |
| 電腦操作 | 原生工具或使用者設定的 Open Computer Use；需輔助使用、螢幕錄製等 macOS 權限。不能以工具握手冒充實際點擊成功。 |
| MCP 擴充 | 連接 Mac 上啟用的 stdio／HTTP 設定，命名隔離、權限檢查；資源、資源範本與提示範本可透過同一連線讀取，分頁游標交由模型續查。 |
| 外掛與技能 | 安裝資訊、啟用狀態、實际工具清單分開；有本機 Skills 時可讀取及使用。OAuth 或外部程式缺少時不可標成可用。 |
| 停止及續聊 | 保留同一 UI 對話與草稿；原生恢復不可用時以有界文字接續；任務進度是補充，沒有重播過去工具副作用。 |

## 可用狀態

`mac_agent_capabilities` 回傳目前實際工具、電腦／瀏覽器及已配置擴充的連線狀態；來源中不包含憑證或連線 Token。安裝名稱、CLI 綠燈及 SSH 成功都不能代替模型回覆和工具結果驗證。

外部專案明確指定第三方工具時，必須接通原工具或取得專案允許的替代方法；本版本不把文字搜尋叫作圖表或影響分析工具。這類外部工具與特定線上帳號不隨 DMG 預先安裝或授權；已設定的 MCP 擴充會以 `mac_ext_` 前綴出現在實際工具清單。

## 發行驗收

先重現問題，再測試修正。來源測試涵蓋無權子目錄、二進位檔、過大網頁、編輯衝突、執行權限、取消／timeout、輸出截斷、任務隔離／重連及 MCP 資源型服務。安裝包使用自己的 Node 執行建立／修改／測試流程，另測原生電腦工具及包內瀏覽器。

真實 Claude 訂閱額度／長上下文、另一台乾淨 Mac、Apple 公證及公開 HTTPS 部署等條件，仍依 [發布檢查](PUBLISH_READINESS.md) 所列結果，不把受控測試宣稱為所有環境驗收。
